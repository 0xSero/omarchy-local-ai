# Lab logos

One-colour logos for the model families in the registry, drawn in the theme's text colour (`currentColor`), so they
sit in the panel's tones like text. From LobeHub's `@lobehub/icons-static-svg` 1.95.1 (MIT,
https://github.com/lobehub/lobe-icons), the plain (mono) variant of each. The marks are their owners' trademarks and
are used only to say whose model a line is.
