01 · Three keys to understand

⌘Command = Super

Omarchy calls this key Super. Your Mac’s Command key reaches it through Moonlight.

⌃Control stays Control

Keep it for terminal commands, agent shortcuts and the desktop prefix below.

⌥Option = Alt

Most daily controls here do not need it. Moonlight’s escape shortcut does.

03 · Windows tile; workspaces separate them

Opening a terminal normally gives it space beside your other windows. Tiled means automatically arranged. Floating means an overlapping window. A workspace is a separate desktop containing its own windows.

Focus is now deliberate

Moving your pointer over a window no longer changes keyboard focus. Click it or switch with ⌘ Tab. This helps prevent typing or closing the wrong window.

Switching is window-based

⌘ Tab cycles windows on the current workspace, rather than macOS’s app switcher. Use Ctrl Space, 1–9 to change workspaces; 0 selects workspace 10.

To move a window to workspace 2: Ctrl Space, then Shift 2. To rearrange nearby windows: Ctrl Space, then Shift + arrow. To focus a neighbor: use the same sequence without Shift.

04 · Start an agent in the right place

  1. Open Local AI

    Ctrl Space, I. You can also use the Agents icon on the OS status bar and choose Local AI.

  2. Expand “Launch agent” at the top

    Pick a running model. Its GPU label helps distinguish models running on different hardware. If none are ready, choose a GPU and load a model first.

  3. Set “Project folder”

    Use an existing Linux folder such as /home/sero/projects/my-project. Ctrl O edits it in Local AI. A Mac path such as /Users/sero/… is a different filesystem.

  4. Choose Pi, OpenCode, Crush, OMP or another available agent

    The list contains installed agents compatible with the selected model. Press Open, then click the new terminal before typing. The launcher enters your project folder inside the terminal.

New terminal ≠ new configured agent. ⌘ D, ⌘ T and ⌘ N in a terminal open another ordinary terminal window. Use Local AI → Open when you want an agent attached to a specific local model.

The keyboard icon lives on the OS status bar. Open it with Ctrl F1 or Ctrl Space, K. It includes a button for this visual guide.

05 · When something feels wrong

Command shortcuts affect my Mac instead of Omarchy

Moonlight must capture system shortcuts. In Moonlight’s input settings, enable Capture system keyboard shortcuts for the stream. If macOS Spotlight or the Mac app switcher appears, that key never reached Omarchy. The Ctrl+Space sequences give you an alternative. Moonlight’s settings can require leaving and reconnecting to the stream.

I typed, but another window received it

Click the intended window once before typing. The new click-to-focus setting stops pointer motion from silently changing focus. A popup or newly opened terminal can still require a click. Closing a terminal can interrupt the agent running inside it.

Copy, paste, Ctrl+C and Ctrl+D feel different

⌘ C copies the terminal selection; ⌘ V pastes. Terminal fallbacks are Ctrl Shift C / Ctrl Shift V. Plain Ctrl C interrupts the running command. At a shell prompt, Ctrl D can exit the shell. Cross-device clipboard syncing between macOS and Omarchy is separate from these remote clipboard shortcuts.

Undo, find or save behave strangely inside an agent

The Command mappings forward Ctrl-based app shortcuts. In a terminal, Ctrl+A can move to the start of a line, Ctrl+F can move the cursor, and Ctrl+Z can suspend a foreground program. At a shell prompt, fg resumes a suspended job. Ctrl+S can pause terminal output on some setups; Ctrl+Q resumes it. Use the agent’s help for its own find, undo and save commands.

The password prompt shows nothing while I type

Linux terminal password prompts normally show no characters or dots. Type the Linux account password and press Enter. This is not automatically your Mac password. If it is rejected, check Caps Lock and keyboard layout; hidden typing alone does not mean the keyboard failed. No password is stored in this guide.

I lost the desktop, or a shortcut seems stuck

Try Esc to leave the desktop shortcut mode. Use Ctrl Space, F to toggle the remote window’s fullscreen, or select a known workspace. If the stream itself is the problem, disconnect using the shortcut below and reconnect. Disconnecting leaves the remote desktop and its running programs alive.

06 · Return to your Mac

Disconnect Moonlight without closing remote apps

Control + Option + Shift + Q

Press all four together. This ends the streaming session; it does not shut down Omarchy. Reconnect to see the same desktop.

Control + Option + Shift + Z toggles mouse/keyboard capture in supported Moonlight versions. The disconnect shortcut above is the clearer exit route.

Omarchy window fullscreen (⌃⌘ F) and Moonlight’s fullscreen stream are separate layers. Changing one does not necessarily change the other.
