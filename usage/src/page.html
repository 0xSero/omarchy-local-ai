How it is counted

Every 12 hours the plugin sends a random install id, its version, the cards it found, how many models run, whether a model has ever answered on it, and since its last check-in how many models it started, how many starts failed, how many agents it opened and how many models it downloaded. Totals only: never which model, agent or folder. Actions wait on the machine until a check-in arrives, so none are lost or sent twice. No address or user agent is stored. "Ran a model, ever" counts installs where a model has answered (6.15.0 and later, including models run before updating) or one was running at a check-in. Turn it off with omarchy-local-ai set ping off. Counting began with 6.13.0 on 10 Oct 2026, so older installs that have not updated are not here. GitHub numbers are recorded daily by the plugin's traffic workflow.
